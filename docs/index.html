Compilar desde el código

Necesitas JDK 17 y el SDK de Android (compileSdk 36).

git clone https://github.com/aurenox-global/Android-SCode.git
cd Android-SCode
./gradlew :app:assembleRelease   # -> app/build/outputs/apk/release/app-universal-release.apk
